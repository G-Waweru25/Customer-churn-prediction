# 🧮 Customer Churn Prediction using ANN
Customer churn prediction using Artificial Neural Networks (Keras/TensorFlow)


This project predicts customer churn based on demographic and banking data using an Artificial Neural Network (ANN) built with TensorFlow/Keras.

## 🚀 Features
- Data preprocessing and encoding
- ANN model training with Keras
- ROC-AUC and confusion matrix visualizations
- Precision, Recall, and F1-score evaluation

## 📊 Model Performance
| Metric | Score |
|--------|--------|
| Accuracy | 84.6% |
| Precision | 81.7% |
| Recall | 30.9% |
| F1-Score | 44.8% |
| ROC-AUC | 85.3% |

## 🧠 Optimal Threshold
Optimal classification threshold: **0.56**

## 📈 Visualizations
The project generates:
- Confusion Matrix
- ROC Curve
- Precision-Recall Curve
- Probability Distribution
